# Своя команда или подрядчик: оценка ИТ-задачи (прототип, FastAPI)

Пользователь описывает задачу, система находит похожие работы в истории (выгрузка ITSM), раскладывает оценку по этапам и сравнивает два сценария: внутренняя команда и подрядчик. Результат: диапазон стоимости и срока, аналоги, допущения, риски, уровень достоверности.

## Запуск
```bash
pip install -r requirements.txt
python scripts/generate_data.py      # демо-данные (уже сгенерированы в data/)
python -m uvicorn app.main:app --port 8000
python -m pytest
```
Открыть http://localhost:8000

## Данные (папка `data/`)
- `itsm_history.csv`: поля как в выгрузке HelpDesk (IM = работа, `Изменение.Номер` = задача CR). **Синтетика**, заменить реальной выгрузкой.
- `market_rates.csv`: ставки подрядчиков по этапам. **Демо-значения**, заменить данными из открытых прайсов (колонка `note`, ссылка на источник).

Проверка качества при загрузке (`app/data_loader.py`): отсеиваются строки без номера CR, встречи, нулевая трудоёмкость, неизвестные типы активности; даты в формате Excel-serial поддерживаются. Сводка видна в интерфейсе.

## Методика (`app/estimator.py`, допущения в `app/config.py`)
1. Сходство описания с историческими CR: TF-IDF + косинус (слова усекаются до 6 символов), берутся до 5 аналогов.
2. Часы по этапам = среднее по аналогам, взвешенное сходством, x множитель сложности. Без аналогов: базовая оценка 240 ч с типовым распределением.
3. Диапазон часов задаётся разбросом аналогов (коэффициент вариации с ограничениями).
4. Внутренний сценарий: часы x ставка x (1 + накладные) x (1 + резерв) + доп. расходы.
5. Подрядчик: часы x доля подрядчика x ставка этапа (p25 / p50 / p75 рынка) + работы заказчика (ТЗ, приёмка) x внутренняя ставка, затем резерв и доп. расходы.
6. Срок = часы / (люди x 6 ч/день) + ожидание старта (очередь внутри, мобилизация подрядчика).
7. Достоверность: сходство лучшего аналога, число аналогов, разброс.

Все параметры можно менять в интерфейсе; формулы намеренно простые, чтобы заменить константы реальными бенчмарками.
